# dotfiles

Personal Linux desktop configuration for i3, rofi, dunst, i3blocks, i3lock,
SSH includes, and a few user-level systemd services.

See [INSTALL.md](INSTALL.md) for package installation, symlink setup, and user
service enablement.

## Contents

- `i3/`: window manager config and OBS desktop-audio routing helper.
- `i3blocks/`: status bar blocks.
- `i3lock/`: lock-screen helper and fallback image assets.
- `rofi/`: launcher config, theme, and numeric-workspace window switcher.
- `dunst/`: notification daemon config and icons.
- `ssh/`: SSH config snippets intended for `Include ~/dotfiles/ssh/*_conf`.
- `systemd/user/`: user services for desktop helpers.
- `p10k/`: Powerlevel10k prompt configuration.
